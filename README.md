## 🎯 About Me

I'm a **Robotics Engineer** and **AI/ML enthusiast** passionate about creating autonomous systems that solve real-world problems. My expertise spans across **computer vision, embedded systems, IoT, robotics middleware (ROS2), and machine learning** — combining hardware, intelligence, and autonomous navigation to build next-generation robotic solutions.

Currently focused on:
- 🤖 **Autonomous Mobile Robots** - Self-navigating systems with ROS2, SLAM, and Nav2
- 👁️ **Computer Vision & AI** - Real-time perception using YOLOv8, TensorFlow, and OpenCV
- 🛣️ **Robot Navigation & Mapping** - SLAM algorithms, path planning, and TF2 transformations
- 🔌 **Embedded IoT Systems** - Arduino, ESP32, and sensor-driven smart devices
- 🧠 **Deep Learning** - Medical imaging, classification, and real-time inference
- 🛰️ **Sensor Integration** - GPS, ultrasonic, thermal, and metallic detection systems
- 🎮 **Simulation & Testing** - Gazebo simulation for robot development and validation
