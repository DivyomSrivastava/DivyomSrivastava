## 👋 About Me

I'm a **Robotics Engineer** passionate about building autonomous systems that solve real-world problems. My work spans computer vision, embedded systems, IoT, ROS 2 middleware, simulation, and machine learning.

### Current Focus

- 🤖 Autonomous mobile robots with ROS 2 and Nav2
- 🛞 Differential-drive control, kinematics, odometry, and teleoperation
- 🎮 Gazebo simulation, URDF/Xacro robot descriptions, and RViz
- 👁️ Computer vision and AI with YOLO, TensorFlow, and OpenCV
- 🔌 Embedded IoT systems with Arduino and ESP32
- 🧭 SLAM, navigation, sensor integration, and real-time robotics
